Les paliers : ce qui se débloque en tranchant

Tout ce qui est public reste ouvert dès la première visite : les votes, les verdicts, les députés, les sources. Ce qui se débloque, c’est ce qui dépend de tes réponses. Rien ne récompense le contenu d’une réponse, seulement le fait de trancher.
